## Jellify

[Jellify](https://github.com/Jellify-Music/App) is a free, open-source music player built for [Jellyfin](https://jellyfin.org/) media servers. It uses **react-native-nitro-player** as its core audio engine.

Jellify relies on **Nitro Player** for all audio playback, playlist management, offline downloads, and car integration. 



### Features

- Stream your entire Jellyfin music library
- Offline playback — download tracks for listening without a connection
- CarPlay and android auto support (WIP)
- Instant Mix radio station creation
- Audio transcoding for bandwidth optimization
- Light and dark mode themes
- Scales to large music libraries
- Over-the-air updates
