---
title: DownloadManager
description: Offline download and storage management API
---

Import:

```typescript
import { DownloadManager } from 'react-native-nitro-player';
```

---

## Configuration

### `configure(config)`

Configure the download manager. **Synchronous.**

```typescript
DownloadManager.configure({
  maxConcurrentDownloads: 3,
  autoRetry: true,
  maxRetryAttempts: 3,
  backgroundDownloadsEnabled: true,
  downloadArtwork: true,
  wifiOnlyDownloads: false,
  storageLocation: 'private',
});
```

See [DownloadConfig](/docs/types#downloadconfig) for all options.

---

### `getConfig()`

Get the current download configuration. **Synchronous.**

```typescript
const config = DownloadManager.getConfig();
```

**Returns:** `DownloadConfig`

---

### `setPlaybackSourcePreference(preference)`

Set whether playback should prefer downloaded or network files. **Synchronous.**

```typescript
DownloadManager.setPlaybackSourcePreference('auto');
```

| Value | Behavior |
|---|---|
| `'auto'` | Use downloaded file if available, otherwise stream |
| `'download'` | Only play downloaded files |
| `'network'` | Always stream from network |

---

### `getPlaybackSourcePreference()`

Get the current playback source preference. **Synchronous.**

```typescript
const pref = DownloadManager.getPlaybackSourcePreference();
```

**Returns:** `PlaybackSource` — `'auto'` | `'download'` | `'network'`

## Download Operations

### `downloadTrack(track, playlistId?)`

Download a single track.

```typescript
const downloadId = await DownloadManager.downloadTrack(track, 'playlist-123');
```

| Param | Type | Required | Description |
|---|---|---|---|
| `track` | `TrackItem` | Yes | Track to download |
| `playlistId` | `string` | No | Associated playlist ID |

**Returns:** `Promise<string>` — Download ID for tracking

---

### `downloadPlaylist(playlistId, tracks)`

Download all tracks in a playlist.

```typescript
const downloadIds = await DownloadManager.downloadPlaylist('playlist-123', tracks);
```

**Returns:** `Promise<string[]>` — Array of download IDs

## Download Status

### `getDownloadTask(downloadId)`

Get a download task by ID. **Synchronous.**

```typescript

```

**Returns:** `DownloadTask | null` — See [DownloadTask](/docs/types#downloadtask)

---

### `getActiveDownloads()`

Get all active (in-progress) download tasks. **Synchronous.**

```typescript
const active = DownloadManager.getActiveDownloads();
```

**Returns:** `DownloadTask[]`

---

### `getQueueStatus()`

Get overall download queue status. **Synchronous.**

```typescript
const status = DownloadManager.getQueueStatus();
// { pendingCount, activeCount, completedCount, failedCount,
//   totalBytesToDownload, totalBytesDownloaded, overallProgress }
```

**Returns:** `DownloadQueueStatus` — See [DownloadQueueStatus](/docs/types#downloadqueuestatus)

---

### `isDownloading(trackId)`

Check if a track is currently downloading. **Synchronous.**

```typescript
const downloading = DownloadManager.isDownloading('track-1');
```

**Returns:** `boolean`

---

### `getDownloadState(trackId)`

Get the download state for a track. **Synchronous.**

```typescript
const state = DownloadManager.getDownloadState('track-1');

```

**Returns:** `Promise<DownloadStorageInfo>` — See [DownloadStorageInfo](/docs/types#downloadstorageinfo)

### `syncDownloads()`

Validate all downloads and clean up orphaned records. Call this after manual file deletion.

```typescript

console.log(`Cleaned ${cleaned} orphaned records`);
```

**Returns:** `Promise<number>` — Number of orphaned records removed

## Events

### `onDownloadProgress(callback)`

Called with progress updates during downloads.

```typescript
DownloadManager.onDownloadProgress((progress) => {
  console.log(`${progress.trackId}: ${(progress.progress * 100).toFixed(1)}%`);
});
```

| Param | Type | Description |
|---|---|---|
| `progress` | `DownloadProgress` | See [DownloadProgress](/docs/types#downloadprogress) |

---

### `onDownloadStateChange(callback)`

Called when a download's state changes.

```typescript
DownloadManager.onDownloadStateChange((downloadId, trackId, state, error) => {
  if (state === 'failed' && error) {
    console.error(`Download failed: ${error.message} (${error.reason})`);
  }
});
```

| Param | Type | Description |
|---|---|---|
| `downloadId` | `string` | Download task ID |
| `trackId` | `string` | Track ID |
| `state` | `DownloadState` | New state |
| `error` | `DownloadError?` | Error details if failed |

---

### `onDownloadComplete(callback)`

Called when a download finishes successfully.

```typescript
DownloadManager.onDownloadComplete((downloadedTrack) => {
  console.log(`Downloaded: ${downloadedTrack.originalTrack.title}`);
  console.log(`Local path: ${downloadedTrack.localPath}`);
});
```

| Param | Type | Description |
|---|---|---|
| `downloadedTrack` | `DownloadedTrack` | The completed download |
