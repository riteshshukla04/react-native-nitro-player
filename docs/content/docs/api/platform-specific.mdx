## AudioDevices

Audio output devices: Bluetooth, USB, wired headphones, the speaker, AirPlay and so on.

```typescript
import { AudioDevices } from 'react-native-nitro-player';
```

- `getCurrentOutputs()` and `onOutputsChange()` work on **iOS and Android**. Use them to react when the output changes, e.g. to apply a per-headphone EQ.
- `getAudioDevices()` and `setAudioDevice()` are **Android only**. On iOS `getAudioDevices()` returns an empty list and `setAudioDevice()` rejects. To let iOS users pick an output, use [`AudioRoutePicker`](#audioroutepicker-ios-only).

### `getCurrentOutputs()`

The devices media plays through right now: usually one, more when audio is mirrored to several outputs (e.g. multi-room AirPlay). **Synchronous.** iOS and Android.

```typescript
const [output] = AudioDevices.getCurrentOutputs();
console.log(`Playing on ${output?.name}`); // e.g. "WH-1000XM4"
```

**Returns:** `TAudioOutput[]`

```typescript
type TAudioOutput = {
  id: string;   // Identifies the output; stays the same when the device reconnects (see below)
  name: string; // e.g. "WH-1000XM4"; wired outputs usually report "Headphones" or "USB Audio"
  type: TAudioOutputType;
};

type TAudioOutputType =
  | 'built_in_speaker'
  | 'built_in_earpiece'
  | 'wired_headphones'
  | 'line_out'
  | 'bluetooth'
  | 'usb'
  | 'airplay'
  | 'car_audio'
  | 'hdmi'
  | 'unknown';
```

**About `id`:** it stays the same when the device reconnects, so you can key settings such as an EQ profile on it.

- Bluetooth outputs are identified by their address: the full address on iOS (the same for A2DP and hands-free), and its last two octets on Android, which is all Android 13+ shows apps without the Nearby devices permission. An LE Audio device can report a different address than the same headphones over classic Bluetooth.
- Other outputs use the port UID on iOS, and type plus name on Android. Two identical wired or USB devices can share an id.

On Android 12 and below, Android can't be asked where media goes, so the output is inferred from the connected devices: the Bluetooth, wired or USB device connected last (on Android 10 and below, Bluetooth first), otherwise the speaker.

### `onOutputsChange(callback)`

Fires when the devices media plays through change: Bluetooth headphones connect or disconnect, headphones or a USB DAC are plugged in, or playback falls back to the speaker. It only fires when the outputs actually change. iOS and Android.

```typescript
AudioDevices.onOutputsChange((outputs, reason) => {
  const output = outputs[0];
  if (output) applyEqProfileFor(output.id);
});
```

The player already pauses when headphones are unplugged or disconnect, so there's no need to pause here.

| Param | Type | Description |
|---|---|---|
| `outputs` | `TAudioOutput[]` | The new outputs, as `getCurrentOutputs()` returns them |
| `reason` | `'device_connected' \| 'device_disconnected' \| 'route_changed'` | Why they changed. Switching from one device to a newly connected one is `device_connected`; `route_changed` covers everything else, e.g. the user picked another output |

Each call adds a listener, and there is no way to remove one, so register it once at app start, not in a component effect. Inside components, use [`useAudioOutputs`](/docs/hooks/platform-hooks#useaudiooutputs).

On Android the event fires when a device connects or disconnects; Android has no public notification for other routing changes.

### `getAudioDevices()` (Android only)

Get all available audio output devices. **Synchronous.** Returns an empty list on iOS.

```typescript
const devices = AudioDevices.getAudioDevices();
```

**Returns:** `TAudioDevice[]`

```typescript
type TAudioDevice = {
  id: number;       // Device ID
  name: string;     // Display name
  type: number;     // Android AudioDeviceInfo type constant
  isActive: boolean; // Currently active output
};
```

---

### `setAudioDevice(deviceId)` (Android only)

Route audio output to a specific device. Rejects on iOS.

```typescript
await AudioDevices.setAudioDevice(device.id);
```

| Param | Type | Required | Description |
|---|---|---|---|
| `deviceId` | `number` | Yes | Device ID from `getAudioDevices()` |

**Returns:** `Promise<void>`

## AudioRoutePicker (iOS Only)

Show the native iOS audio route picker for AirPlay and Bluetooth output selection.

```typescript
import { AudioRoutePicker } from 'react-native-nitro-player';
```

> `AudioRoutePicker` is `null` on Android. Always check availability before use.

### `showRoutePicker()`

Present the native `AVRoutePickerView` to let the user select an audio output. **Synchronous.**

```typescript
AudioRoutePicker?.showRoutePicker();
```

## AndroidAutoMediaLibrary (Android Only)

Configure the media browsing structure that appears in Android Auto.

```typescript
import { AndroidAutoMediaLibrary } from 'react-native-nitro-player';
```

> `AndroidAutoMediaLibrary` is `null` on iOS. For a simpler API, use the `AndroidAutoMediaLibraryHelper` utility below.

### `setMediaLibrary(libraryJson)`

Set the Android Auto media library structure as a JSON string.

```typescript
await AndroidAutoMediaLibrary?.setMediaLibrary(JSON.stringify(library));
```

| Param | Type | Required | Description |
|---|---|---|---|
| `libraryJson` | `string` | Yes | JSON string of `MediaLibrary` |

**Returns:** `Promise<void>`

---

### `clearMediaLibrary()`

Clear the custom media library. Falls back to showing all playlists.

```typescript
await AndroidAutoMediaLibrary?.clearMediaLibrary();
```

**Returns:** `Promise<void>`

---

## AndroidAutoMediaLibraryHelper

A convenience wrapper around `AndroidAutoMediaLibrary` that handles JSON serialization and null checks.

```typescript
import { AndroidAutoMediaLibraryHelper } from 'react-native-nitro-player';
```

### `set(library)`

Set the media library structure with a typed object.

```typescript
import type { MediaLibrary } from 'react-native-nitro-player';

const library: MediaLibrary = {
  layoutType: 'list',
  rootItems: [
    {
      id: 'favorites',
      title: 'Favorites',
      mediaType: 'folder',
      isPlayable: false,
      children: [
        {
          id: 'fav-playlist',
          title: 'My Top Tracks',
          mediaType: 'playlist',
          isPlayable: true,
          playlistId: 'playlist-123',
        },
      ],
    },
    {
      id: 'recent',
      title: 'Recently Played',
      mediaType: 'playlist',
      isPlayable: true,
      playlistId: 'playlist-recent',
    },
  ],
  appName: 'My Music App',
};

AndroidAutoMediaLibraryHelper.set(library);
```

### `clear()`

```typescript
AndroidAutoMediaLibraryHelper.clear();
```

### `isAvailable()`

Check if Android Auto media library is available (always `false` on iOS).

```typescript
if (AndroidAutoMediaLibraryHelper.isAvailable()) {
  AndroidAutoMediaLibraryHelper.set(library);
}
```

**Returns:** `boolean`

## MediaLibrary Types

```typescript
interface MediaLibrary {
  layoutType: LayoutType;    // 'grid' | 'list'
  rootItems: MediaItem[];
  appName?: string;
  appIconUrl?: string;
}

interface MediaItem {
  id: string;
  title: string;
  subtitle?: string;
  iconUrl?: string;
  isPlayable: boolean;
  mediaType: MediaType;      // 'folder' | 'audio' | 'playlist'
  playlistId?: string;       // Links to a PlayerQueue playlist
  children?: MediaItem[];    // For browsable folders
  layoutType?: LayoutType;   // Override parent's layout
}
```
