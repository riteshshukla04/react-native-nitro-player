## Playlist Management

### `createPlaylist(name, description?, artwork?)`

Create a new playlist.

```typescript
const playlistId = await PlayerQueue.createPlaylist(
  'Road Trip',
  'Summer driving playlist',
  'https://example.com/art/road-trip.jpg'
);
```

| Param | Type | Required | Description |
|---|---|---|---|
| `name` | `string` | Yes | Playlist name |
| `description` | `string` | No | Playlist description |
| `artwork` | `string` | No | Artwork URL |

**Returns:** `Promise<string>` — The new playlist ID

---

### `deletePlaylist(playlistId)`

Delete a playlist and all its tracks.

```typescript
await PlayerQueue.deletePlaylist('playlist-123');
```

**Returns:** `Promise<void>`

---

### `updatePlaylist(playlistId, name?, description?, artwork?)`

Update playlist metadata.

```typescript
await PlayerQueue.updatePlaylist('playlist-123', 'New Name', 'New description');
```

| Param | Type | Required | Description |
|---|---|---|---|
| `playlistId` | `string` | Yes | Playlist to update |
| `name` | `string` | No | New name |
| `description` | `string` | No | New description |
| `artwork` | `string` | No | New artwork URL |

**Returns:** `Promise<void>`

---

### `getPlaylist(playlistId)`

Get a playlist by ID. **Synchronous.**

```typescript
const playlist = PlayerQueue.getPlaylist('playlist-123');
// Returns null if not found
```

**Returns:** `Playlist | null` — See [Playlist](/docs/types#playlist)

---

### `getAllPlaylists()`

Get all playlists. **Synchronous.**

```typescript
const playlists = PlayerQueue.getAllPlaylists();
```

**Returns:** `Playlist[]`

## Track Management

### `addTrackToPlaylist(playlistId, track, index?)`

Add a single track to a playlist.

```typescript
await PlayerQueue.addTrackToPlaylist('playlist-123', {
  id: 'track-1',
  title: 'New Song',
  artist: 'Artist',
  album: 'Album',
  duration: 210,
  url: 'https://example.com/song.mp3',
});
```

| Param | Type | Required | Description |
|---|---|---|---|
| `playlistId` | `string` | Yes | Target playlist |
| `track` | `TrackItem` | Yes | Track to add |
| `index` | `number` | No | Insert position (appends if omitted) |

**Returns:** `Promise<void>`

---

### `addTracksToPlaylist(playlistId, tracks, index?)`

Add multiple tracks to a playlist.

```typescript
await PlayerQueue.addTracksToPlaylist('playlist-123', tracks, 0); // Insert at beginning
```

| Param | Type | Required | Description |
|---|---|---|---|
| `playlistId` | `string` | Yes | Target playlist |
| `tracks` | `TrackItem[]` | Yes | Tracks to add |
| `index` | `number` | No | Insert position (appends if omitted) |

**Returns:** `Promise<void>`

---

### `removeTrackFromPlaylist(playlistId, trackId)`

Remove a track from a playlist.

```typescript
await PlayerQueue.removeTrackFromPlaylist('playlist-123', 'track-1');
```

Unknown track ids are ignored; only a missing playlist rejects.
If the removed track is not the one playing, playback is untouched. If it *is* playing,
playback moves to the next surviving track. If it was the last track in the playlist, it
finishes once (it never loops, whatever the repeat mode) and any queued Play Next / Up Next
tracks still play.

**Returns:** `Promise<void>`

---

### `reorderTrackInPlaylist(playlistId, trackId, newIndex)`

Move a track to a new position within a playlist.

```typescript
await PlayerQueue.reorderTrackInPlaylist('playlist-123', 'track-1', 3);
```

| Param | Type | Required | Description |
|---|---|---|---|
| `playlistId` | `string` | Yes | Target playlist |
| `trackId` | `string` | Yes | Track to move |
| `newIndex` | `number` | Yes | New 0-based position |

**Returns:** `Promise<void>`

---

### `removeTracksFromPlaylist(playlistId, trackIds)`

Remove several tracks in a single native call: one save, one event, one queue rebuild.

```typescript
await PlayerQueue.removeTracksFromPlaylist('playlist-123', ['track-1', 'track-7']);
```

| Param | Type | Required | Description |
|---|---|---|---|
| `playlistId` | `string` | Yes | Target playlist |
| `trackIds` | `string[]` | Yes | Tracks to remove; unknown ids are skipped |

Rejects only when the playlist does not exist. Removal semantics match
[`removeTrackFromPlaylist`](#removetrackfromplaylistplaylistid-trackid), and the currently
playing track is never interrupted unless it is itself removed.

**Returns:** `Promise<void>`

---

### `shufflePlaylist(playlistId, options?)`

Shuffle a playlist in place (Fisher-Yates). The new order is stored and persisted — there is
no shuffle mode to turn off, and no hidden original order to restore.

```typescript
// Current track stays put, everything else is reshuffled behind it
await PlayerQueue.shufflePlaylist('playlist-123');

// Shuffle everything, current track keeps playing wherever it lands
await PlayerQueue.shufflePlaylist('playlist-123', { keepCurrentTrackFirst: false });
```

| Param | Type | Required | Description |
|---|---|---|---|
| `playlistId` | `string` | Yes | Playlist to shuffle |
| `options` | `ShufflePlaylistOptions` | No | See [ShufflePlaylistOptions](/docs/types#shuffleplaylistoptions) |

When the shuffled playlist is the one playing, the playing track is never restarted: its
position, buffer and playback state are untouched, and no `onChangeTrack` fires. The upcoming
tracks are re-queued from the new order, so the next transition stays gapless as long as the
call happens before the player's normal lead time into that transition — a shuffle in the last
moment of a track behaves like a manual skip.

Fires `onPlaylistChanged` with `'update'`. When the promise resolves, the stored playlist,
`getActualQueue()` and `getState().currentIndex` all reflect the new order.

While casting, the receiver queue is updated with the same current-preserving operations.
If the receiver's state cannot be trusted (another sender changed the queue, or a request
failed), the queue is reloaded at the current position instead, which is briefly audible.

**Returns:** `Promise<void>`

## Playback

### `loadPlaylist(playlistId)`

Load a playlist into the player. Call `TrackPlayer.play()` after to start playback.

```typescript
await PlayerQueue.loadPlaylist('playlist-123');
await TrackPlayer.play();
```

**Returns:** `Promise<void>`

---

### `getCurrentPlaylistId()`

Get the currently loaded playlist ID. **Synchronous.**

```typescript
const id = PlayerQueue.getCurrentPlaylistId();
// Returns null if no playlist is loaded
```

**Returns:** `string | null`

---

## Events

### `onPlaylistsChanged(callback)`

Called when the overall list of playlists changes (create, delete, etc.).

```typescript
PlayerQueue.onPlaylistsChanged((playlists, operation) => {
  console.log(`Playlists ${operation}: ${playlists.length} total`);
});
```

| Param | Type | Description |
|---|---|---|
| `playlists` | `Playlist[]` | All current playlists |
| `operation` | `QueueOperation?` | `'add'` \| `'remove'` \| `'clear'` \| `'update'` |

---

### `onPlaylistChanged(callback)`

Called when a specific playlist is modified (tracks added, removed, reordered).

```typescript
PlayerQueue.onPlaylistChanged((playlistId, playlist, operation) => {
  console.log(`Playlist ${playlistId} ${operation}: ${playlist.tracks.length} tracks`);
});
```

| Param | Type | Description |
|---|---|---|
| `playlistId` | `string` | Modified playlist ID |
| `playlist` | `Playlist` | Updated playlist object |
| `operation` | `QueueOperation?` | `'add'` \| `'remove'` \| `'clear'` \| `'update'` |
