## Prerequisites

- React Native **0.76+**
- [react-native-nitro-modules](https://github.com/mrousavy/nitro) **0.35+**

## Install

```bash tab="npm"
npm install react-native-nitro-player react-native-nitro-modules
```

```bash tab="yarn"
yarn add react-native-nitro-player react-native-nitro-modules
```

```bash tab="bun"
bun add react-native-nitro-player react-native-nitro-modules
```

## iOS Setup

Install CocoaPods:

```bash
cd ios && pod install
```

## Android Setup

No additional steps needed — auto-linking handles everything.

### Android Permissions

Add these to your `android/app/src/main/AndroidManifest.xml` for background playback:

```xml
<uses-permission android:name="android.permission.INTERNET" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE" />
<uses-permission android:name="android.permission.FOREGROUND_SERVICE_MEDIA_PLAYBACK" />
```

If you plan to use offline downloads, see the [Offline Playback](/docs/guides/offline-playback) guide for additional permissions and WorkManager setup.

## Configuration

Configure the player early in your app lifecycle (e.g., in your root component):

```typescript
import { TrackPlayer } from 'react-native-nitro-player';

await TrackPlayer.configure({
  androidAutoEnabled: false,
  carPlayEnabled: false,
  showInNotification: true,
  remoteSkipForwardInterval: 15,
  remoteSkipBackwardInterval: 15,
  lookaheadCount: 5,
});
```

| Option | Type | Default | Description |
|---|---|---|---|
| `androidAutoEnabled` | `boolean` | `false` | Enable Android Auto integration |
| `carPlayEnabled` | `boolean` | `false` | Enable CarPlay integration |
| `showInNotification` | `boolean` | `true` | Show playback in notification/Control Center |
| `remoteSkipForwardInterval` | `number` | `15` | Seconds to skip forward from remote controls |
| `remoteSkipBackwardInterval` | `number` | `15` | Seconds to skip backward from remote controls |
| `lookaheadCount` | `number` | `5` | Tracks to preload URLs for (lazy loading) |

Remote skip intervals drive the iOS AirPods/Control Center fixed skip buttons and the Android Media3 seek back/forward notification buttons. iOS also exposes remote playback rates: `0.5, 1.0, 1.25, 1.5, 1.75, 2.0`; Android exposes no playback-rate media button. Custom intervals apply to local playback; during a Google Cast session the receiver skips by a fixed 15 seconds.
